# Архитектура курсового проекта: EduGen Platform

## 1. Общая структура проекта
Проект представляет собой монорепозиторий, состоящий из двух основных частей, с перспективой добавления бэкенда:
1. **`frontend`** — клиентское приложение (SPA) на React. Отвечает за интерфейс преподавателя и маршрутизацию.
2. **`ui-library`** — переиспользуемая библиотека UI-компонентов.
3. **`backend`** *(в разработке)* — серверная часть на Node.js для генерации и проверки заданий.

## 2. Используемые библиотеки и их версии
Версии сторонних библиотек соответствуют или превышают требования примера ЛР4:
*   **React** `^19.3.0` — библиотека для создания пользовательских интерфейсов.
*   **React DOM** `^19.3.0` — рендеринг React-компонентов в DOM.
*   **React Router DOM** `^7.0.0` — маршрутизация в одностраничном приложении (SPA).
*   **TypeScript** `~5.9.3` — строгая типизация.
*   **Vite** `^7.1.7` — сборщик проекта.
*   **Jest** `^30.2.0` + **React Testing Library** — юнит-тестирование.
*   **ESLint** `^9.36.0` — линтинг и проверка стиля кода.

## 3. Разрабатываемые компоненты
**В библиотеке `ui-library`:**
*   `Button` — универсальная кнопка с поддержкой разных вариантов (primary, secondary).
*   `Card` — переиспользуемый контейнер для отображения блоков контента с заголовком.

**В приложении `frontend` (Страницы):**
*   `HomePage` — приветственная страница с описанием платформы.
*   `LoginPage` — страница авторизации.
*   `DashboardPage` — личный кабинет преподавателя.
*   `GeneratePage` — интерфейс генерации заданий.
*   `CheckPage` — интерфейс проверки ответов студентов.
*   `StatsPage` — панель со статистикой.

### 4. Структура роутинга
*   `/` — `HomePage` (Главная).
*   `/login` — `LoginPage` (Авторизация преподавателя).
*   `/dashboard` — `DashboardPage` (Личный кабинет).
*   `/generate` — `GeneratePage` (Генерация заданий).
*   `/check` — `CheckPage` (Проверка работ).
*   `/stats` — `StatsPage` (Аналитика).
*   **`/task/:id` — страница прохождения задания (для студентов).** Студент переходит по уникальной ссылке, которую сгенерировал преподаватель, вводит свое имя и отвечает на вопрос. Регистрация для студента не требуется (упрощенный вход по ссылке).

## 5. Использование библиотеки
Библиотека `ui-library` подключена в `frontend` через `package.json` как локальная зависимость (`file:../ui-library`) и импортируется по имени пакета: `import { Button, Card } from '@edu-gen/ui-library'`.
